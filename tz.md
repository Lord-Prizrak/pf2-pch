В текущей директории находится несколько файлов содержащих листы персонажей НРИ PathFinder 2e.

Две большие задачи:
1. Первая задача. Создать интерактивный лист персонажа в html-файле. Требования:
    - Сохранения данных одного или множества листов персонажа в браузере, html и/или на сервере.
    - HTML содержит в себе всё что нужно для работы, в том числе и данные одного (или нескольких) персонажа, если сохраняем html с конкретным персонажем
    - Данные всегда сохраняются в виде json, независимо от места хранения
    - Лист персонажа можно импортировать и экспортировать:
        - В виде копирования/вставки json данных в/из буфера обмена
        - В виде загрузки json файла
        - Из/в html файла листа персонажа
        - С/на сервер
    - Блок для управления серверами, со списками персонажей на них
    - Список персонажей на разных серверах
    - Переключение между персонажами

2. Вторая задача. Создать backend сервер для хранения листов персонажа. Требования:
    - Реализация backend на языке: Golang
    - Авторизация
    - Загрузка/выгрузка персонажей по API
    - Страница авторизации
    - Страница с чистым листом персонажа
    - Страница пользователя с данными о нём и его персонажами, и ключами для доступа по API

Используй субагентов.
Делай коммиты.
